# Trechos {#snippets}

## Trabalho em andamento {#work-in-progress}

A documentação do Adobe Experience Manager 6.6 está em andamento. O AEM 6.6 não está disponível para o público geral (GA) e esta documentação ainda não é pública.

## O editor universal possui preferência em relação ao editor de SPA {#ue-over-spa}

>[!IMPORTANT]
>
>O editor de SPA foi descontinuado para novos projetos.Ele continuará funcionando com projetos existentes da Adobe, mas não deve ser usado para novos projetos. Os editores preferidos para gerenciar conteúdo headless no AEM agora são:
>
>* O [editor universal](/help/sites-developing/universal-editor/introduction.md) para editar conteúdo headless visualmente.
>* O [editor de fragmentos de conteúdo](/help/assets/content-fragments/content-fragments-managing.md) para editar conteúdo headless com base em formulários.
